## 2N3904 特性曲線：電路

```
 電源 5V ──┬─ 可變電阻 100kΩ ─┬─ GND
           (腳1)      W│     (腳3)
                       └─ RB 100kΩ ─── B
                                         ╲│   2N3904
 產生器 + (三角波 0~10V) ───────────────── C │
                                         ╱│
                                          E ── RE 100Ω ── GND
 產生器 −、示波器兩支接地夾、電源 GND：全部接麵包板 GND 軌

 CH1 探針 → C（X 軸 = VCE，1 V/div）
 CH2 探針 → E（Y 軸 = RE 電壓 = IC × 100 Ω，0.1 V/div = 1 mA/div）
```

- IB = (W 腳電壓 − VBE) / 100 kΩ：旋鈕往腳 1（5 V）轉 → IB 變大，約 0 ~ 40 µA
- 每個 IB 對應一條曲線；β ≈ IC / IB ≈ 200（2N3904）
- VCE 很小（< 0.3 V）的陡峭段是**飽和區**，曲線變平後是**放大區**（IC ≈ β·IB，幾乎跟 VCE 無關），IB = 0 那條貼在底部是**截止區**
- 示波器量到的 CH1 其實是 VC = VCE + VRE，VRE 最多約 0.6 V，所以曲線會往右偏一點點

## LDR 小夜燈：電路

```
 9V(+) ──┬── 47kΩ ──┬── B        BC547（平面朝自己：C B E）
         │          │
         │        LDR            C ── LED ── 470Ω ── 9V(+)
         │          │            E ── 9V(−)
 9V(−) ──┴──────────┘
```

- 47 kΩ 與光敏電阻分壓決定基極電壓：亮 → LDR 約 1–3 kΩ → 基極 < 0.5 V → BC547 截止，LED 熄
- 暗 → LDR 幾十 kΩ 以上 → 基極 > 0.65 V → BC547 飽和導通，LED 約 14 mA
- 想讓它「更暗才亮」：把 47 kΩ 換大（例如 100 kΩ）；「沒那麼暗就亮」：換小
- 電池跟電源供應器是分開的：三用電表黑棒要接電池 −（範例已經接在電源軌 B −）

## NE555 閃爍燈（CH224K 供電）：電路

```
 CH224K VOUT(9V) ─┬─ NE555 第 8 腳 VCC、第 4 腳 RESET
                  ├─ R1 1kΩ ─ 第 7 腳 DIS ─ R2 10kΩ ─┬─ 第 6 腳 THR
                  │                                  ├─ 第 2 腳 TRIG
                  │                                  └─ C 47µF ─ GND
                  └─ 2.2kΩ ─ 綠色 LED ─ CH224K PG（協商成功時拉低 → 亮）
 第 5 腳 CTRL ─ 0.01µF（103）─ GND        第 1 腳 GND ─ CH224K GND
 第 3 腳 OUT ─ 470Ω ─ 紅色 LED ─ GND
```

- 電容經 R1 + R2 充電到 2/3 VCC → 輸出變低、第 7 腳放電；經 R2 放電到 1/3 VCC → 輸出變高，一直重複
- 充電時間 ≈ 0.693·(R1 + R2)·C（OUT 高），放電時間 ≈ 0.693·R2·C（OUT 低）→ f ≈ 1.44 / ((R1 + 2·R2)·C) ≈ 1.46 Hz
- 把 C 換成 104（0.1 µF）就變成約 690 Hz（「NE555 無穩態振盪」範例用示波器看）
